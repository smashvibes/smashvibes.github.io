  • One category at a time: Kids singles plays first, then kids pairs, then adults. The next category starts as soon as the one before reaches its semi-finals, using the courts the semis and final leave free. The earlier category always gets a court first.
  • Mix categories: matches go to the first free court. Longer chains (adult group rounds) are picked first so the finals aren't held up. Sometimes a court is held free for a few minutes so an adult group match can start on time.
  • A player can't start a match until their previous one ends plus the rest time.
  • Adult group matches are assumed to be first to 30 like the U17 early rounds. The website doesn't say, so change the slider if it's different.
